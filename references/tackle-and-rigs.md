# 作钓方案参考（台钓 / 传统钓 / 筏钓）

配置数值是起点，不是教条。实际按目标鱼个体大小、水情、装备条件调整。

---

## 1. 台钓（默认）

**适用**：静水或缓流，鲫鲤为主，追求灵敏度与信号清晰度。

| 项目 | 推荐范围 |
|---|---|
| 鱼竿 | 3.6 - 5.4 m，调性 28 / 37 调 |
| 主线 | 0.8 - 3.0 号 |
| 子线 | 0.4 - 2.0 号（子线号数约为主线的一半） |
| 鱼钩 | 袖钩 3 - 5 号（鲫）；伊势尼 5 - 7 号（鲤） |
| 浮漂 | 立式浮漂，调 4 钓 2 或调平水钓 2 - 3 目 |
| 打窝 | 春：酒米 + 腥香；夏：谷香 / 酵香；秋：腥香；冬：酒米 + 浓腥 |

**鱼种 - 季节线组对应**

| 目标鱼 | 主线/子线 | 钩型 |
|---|---|---|
| 鲫鱼（0.1 - 0.5 kg） | 1.0 / 0.6 | 袖 3 - 5 |
| 鲫鱼（大板鲫） | 1.2 / 0.8 | 袖 5 - 6 |
| 鲤鱼（1 - 3 kg） | 2.0 / 1.2 | 伊势尼 5 - 7 |
| 草鱼（2 - 5 kg） | 3.0 / 2.0 | 伊势尼 7 - 9 |
| 鲢鳙 | 3.0 / 2.0 | 伊势尼 8 - 10 + 大漂 |

**优劣势**：灵敏度高、信号清晰；抗风浪弱、复杂地形受限。

---

## 2. 传统钓

**适用**：水草密集、障碍物多、地形复杂的野塘与河沟，鲫鱼为主，操作简便。

| 项目 | 推荐范围 |
|---|---|
| 鱼竿 | 5.4 - 9 m 长竿（长竿短线），软调 |
| 主线 | 1.5 - 3.0 号 |
| 子线 | 1.0 - 2.0 号 |
| 鱼钩 | 伊豆 4 - 6 号 / 袖钩 5 - 7 号 |
| 浮漂 | 七星漂 / 立漂，调平水钓 2 - 3 目 |
| 打窝 | 酒米为主，少量多次补窝 |

**优劣势**：适应复杂地形、抗干扰强；灵敏度较低、不适合远投。

---

## 3. 筏钓

**适用**：桥墩、码头、深水区；冬季鱼口相对稳定。

| 项目 | 推荐范围 |
|---|---|
| 鱼竿 | 1 - 2 m 筏钓竿，软调，配筏钓轮 |
| 主线 | 0.8 - 2.0 号 |
| 子线 | 0.4 - 1.5 号 |
| 鱼钩 | 袖 2 - 4 号 / 伊豆 3 - 5 号 |
| 浮漂 | 筏钓漂，或看竿稍 / 线讯号 |
| 打窝 | 需打窝器定点；腥香为主 |

**优劣势**：不受水深限制、冬季口好；需要平台/桥墩条件，装备成本较高。

---

## 4. 味型速查（季节基础 + 鱼种修正 + 天气修正）

| 季节 | 基础味型 | 说明 |
|---|---|---|
| 春 | 腥香 | 水温回升，鱼从深水向浅滩迁移，需要动物蛋白 |
| 夏 | 谷香 / 果酸 | 高温期，酸味与果香能降低鱼的警惕；缺氧时加果香 |
| 秋 | 腥香 | 育肥储备期，高蛋白腥味有效 |
| 冬 | 浓腥 | 低温，鱼代谢慢，需要强刺激与高热量 |

**关键鱼种修正**

| 鱼种 | 春 | 夏 | 秋 | 冬 |
|---|---|---|---|---|
| 鲫鱼 | 腥香 | 谷香 / 果酸 | 腥香 | 浓腥 |
| 鲤鱼 | 腥香 | 谷香 / 酵香 | 腥香 | 浓腥 |
| 草鱼 | 谷香 | 果酸 / 酵香 | 谷香 | 少钓 |
| 鲢鳙 | 酸香 | 酸臭 / 果酸 | 酸香 | 少钓 |
| 翘嘴 | 腥 | 腥 | 腥香 | 浓腥 |
| 黄颡 / 鲶鱼 | 腥 | 腥 | 腥 | 腥（活饵更优） |

**天气修正**
- 小雨天 → 腥味可加强，活饵效果显著提升
- 闷热低压 → 无论什么味型，鱼的开口意愿都低，味型不是解药
- 北风降温后 → 下风口，腥味为主

## 5. 钓位速查

| 水域 | 推荐钓位 |
|---|---|
| 江河 | 回水湾、洄流区、桥墩旁、支流汇入处 |
| 湖泊 | 水草边、铧尖、深浅交界、迎风坡 |
| 城市河道 | 路桥下、闸口旁（有流水时）、水草区；夜间优于白天 |
| 黑坑 | 塘角、增氧机旁、投饵区、下风口；新鱼当天下风口近岸 |
| 水库 | 大坝附近、湾汊、老钓点、淹没的老河道 |
| 闸口 | 闸上下游 5 - 20 m 的洄流区 |
| 山涧 / 溪流 | 缓流区、石缝旁、入水口、深潭出口 |
| 鱼塘 | 投饵区、增氧机旁、塘角、坝口 |

**通用加分钓位**
- **树荫下**：夏季高温时段，水温低、光线弱、鱼警惕性下降
- **桥墩旁**：遮蔽 + 食物聚集，掠食性鱼（翘嘴 / 鳜 / 黑鱼）常驻
- **坝口 / 闸口**：水流交换带来溶氧与食物，鲤鲫草聚集

**避开的钓位**
- 高压线下（致命）
- 湿滑陡岸、无退路的孤立礁石
- 悬崖正下方、可能有落石的岩壁旁
