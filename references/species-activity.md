# 鱼种活跃参数与适宜度模型

## 1. 关于「季节划分」的口径 —— 原技能有自相矛盾，必须统一

原 `SKILL.md` 里同时存在两套互斥的划分：

- 1 节写「**按农历月份**判断季节」（正二三春、四五六夏…）
- 版本历史 v1.11 却写「修正季节划分（**5 月归入夏季，符合气象学标准**）」，v1.12 又改回农历标准

这两条不可能同时成立。更严重的是农历法的实际后果：2026 年农历五月落在公历 6/15 - 7/13，而 2026 年闰六月使农历四月延后到 5/17 起 —— 农历月份与公历月份最多可差约 6 周，用它判断「现在是什么季节」会出现「公历 8 月被算成夏季」这类巧合正确、以及在闰月年份错得离谱的情况。

**本技能采用的唯一口径：节气法（近似）。**

| 季节 | 起始 | 近似公历日期 |
|---|---|---|
| 春 | 立春 | 2 月 4 日前后 |
| 夏 | 立夏 | 5 月 6 日前后 |
| 秋 | 立秋 | 8 月 7 日前后 |
| 冬 | 立冬 | 11 月 7 日前后 |

`scripts/fishing_conditions.py` 的 `season_of()` 按此实现（节气日近似值，误差 ±1 天，对钓鱼评估无影响）。

**结论**：农历只用于**月相**推算，不用于季节判定。原技能要求模型先算农历再判季节，是多余且有害的一步 —— 已从工作流中移除。

## 2. 适宜度评分模型（修正版）

### 2.1 因子权重（必须合计 100%）

原技能的权重表合计只有 **75%**（25+20+15+15），而 2.1.1 的「评分计算示例」却按 7 个因子算出了 100 分，含两个从未出现在权重表里的因子（窗口期重叠 15%、季节基准 10%）。**这是原技能最硬的内部矛盾。**

修正后：

| 因子 | 权重 | 判定规则 |
|---|---|---|
| 温度适活性 | 25 | 落在目标鱼适温区间中部得满分；超出区间扣分 |
| 气压 | 20 | ≥1013 hPa 且平稳/上升 → 满分；3 小时内下降 >3 hPa → 扣 15 - 20；<1000 hPa 且闷热 → 接近 0 |
| 降水/湿度 | 15 | 小雨 → 满分（甚至溢出）；多云/阴 → 12；晴无风 → 8；中雨以上 → 5；雷雨 → 安全否决；湿度 >95% 且低压 → 判为缺氧，扣 10 |
| 风力 | 15 | 2 - 3 级 → 满分；1 级 → 12；4 级 → 6；5 级 → 3；≥6 级 → 安全否决 |
| 窗口期重叠 | 15 | 黄金窗口与适宜温压重合 → 满分；部分重合 → 8；不重合 → 3 |
| 季节基准 | 10 | 春秋 → 满分；夏 → 8（早晚满分、午间 3）；冬 → 6（仅温暖午间满分） |
| **合计** | **100** | — |

### 2.2 修正项（叠加在基础分之上）

| 类型 | 条件 | 分数 |
|---|---|---|
| 鱼种 | 目标鱼在活跃时段（如黄颡/鲶鱼夜行） | +10 |
| 鱼种 | 目标鱼明显不适温（如 8°C 钓罗非） | -25 |
| 水域 - 闸口 | 有水流交换 | +10 |
| 水域 - 山涧 | 水温 <20°C | +15 |
| 水域 - 溪流 | 流水、鱼活性高 | +5 |
| 水域 - 黑坑/鱼塘 | 当天放新鱼 | +15 |
| 水域 - 城市河道 | 夜钓 | +5 |
| 水域 - 江河 | 气压权重下调（流水溶氧高，抗低压） | 气压项权重 ×0.75，其余按比例补回 |
| 天气 | 小雨 | +20 |
| 天气 | 多云/阴 | +5 |
| 天气 | 晴无风 | -15 |
| 天气 | 闷热低压（雷雨前） | -30 |
| 天气 | 北风降温（夏季） | +10 |
| 天气 | 大雨后涨水 | +10 |
| 天气 | 24 小时内降温 ≥10°C | -15 |
| 月相 | 见 §3 | ±5 - 10 |

**输出约束**：基础分 + 修正后，**最终适宜度必须夹到 [0, 100]**。原技能示例给「100 - 105 分（满分 100，可超）」是错的 —— 超 100 的分数无法与他项比较，也破坏了「分数即百分比」的语义。若需表达「超出预期」，用文字补充，不要突破上限。

### 2.3 分时段

分别计算**白天**（日出 - 日落）与**夜晚**（日落 - 次日日出）两个分数。窗口期由日出日落时刻推算：

- 白天黄金窗口：日出后 2 小时内、日落前 2 小时内
- 夜钓黄金窗口：日落前 1 小时起至 22:00；次日日出前 2 小时
- 午间低谷：11:00 - 15:00（夏季高温时段尤其明显）

## 4. 月相规则

| 月相 | 农历日 | 夜钓修正 | 昼钓修正 | 原理 |
|---|---|---|---|---|
| 新月（朔） | 初一前后 | +10 | 0 | 无月光，鱼警惕性低 |
| 蛾眉月 | 初三 - 初六 | +5 | 0 | 月光弱 |
| 上弦月 | 初七 - 初九 | 0（前夜 -5 / 后夜 +5 相抵） | 0 | 前半夜有月光 |
| 盈凸月 | 初十 - 十三 | -5 | 0 | 月光渐强 |
| 满月（望） | 十四 - 十七 | -10 | +5 | 整夜明亮，鱼趋深且警惕 |
| 亏凸月 | 十八 - 二十一 | -5 | 0 | — |
| 下弦月 | 二十二 - 二十四 | 0（前夜 +5 / 后夜 -5 相抵） | 0 | 后半夜有月光 |
| 残月 | 二十五 - 二十九 | +5 | 0 | 月光弱 |

**特殊规则**
- 月出后 1 小时、月落前 1 小时 → 掠食性鱼（翘嘴 / 鳜 / 黑鱼）+10
- 初一、十五民间称「大鱼日」→ 全天 +5（经验性，非严格科学依据，**应向用户标注为经验规则**）
- 月相数据源：优先用 `wttr.in` 的 `astronomy.moon_phase` / `moon_illumination`；本地农历推算作为交叉校验，二者照度差 >25% 时给出提示

## 6. 安全否决项（触发即终止，不计算分数）

**物理安全**
1. 雷暴、强对流、冰雹、暴雪
2. 风力 ≥6 级
3. 钓位上方有高压电线（碳素竿导电，致命）
4. 洪水期、水质异常（发臭、明显污染）
5. 湿滑陡岸、无退路的孤立礁石、悬崖正下方
6. 夜间气温 <5°C 且无专业御寒装备（需先询问）

**法律合规**
7. 用户在禁渔区 / 禁渔期 / 饮用水源保护区垂钓
8. 用户指定保护物种为目标鱼种
9. 用户要求使用电鱼、毒鱼、可视锚鱼等非法手段

**触发后的处理**：不是询问「是否确认出钓」—— 属于 7、8、9 的直接终止评估并说明依据；属于 1 - 6 的可提示风险大幅扣分并要求用户确认装备与天气判断，但**不得输出鼓励性建议**。

## 7. 民俗与经验的定性说明

原技能把不少民间经验当作定量规则使用。以下条目**保留但必须标注性质**，不得与可验证因子混为一谈：

| 条目 | 性质 | 建议表述 |
|---|---|---|
| 初一、十五「大鱼日」 | 民间经验 | 「部分钓友的经验」 |
| 月相对鱼口的影响 | 有潮汐/光照机制支撑，但强度有争议 | 「一般规律」 |
| 味型 × 季节对应 | 经验总结，来源分散 | 「常见做法」 |
| 气压 ≥1013 hPa 有利 | 有溶氧机制支撑 | 可直接定量 |
| 小雨天鱼口好 | 有溶氧与光线机制支撑 | 可直接定量 |

**原则**：可验证的机制性因子给分数；经验性条目给建议但不加权，或加权时明确标注「经验规则」。
