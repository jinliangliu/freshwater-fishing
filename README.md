# 淡水野钓顾问 (Freshwater Fishing Advisor)

WorkBuddy 技能 —— 依据真实气象、天文与法规数据，给出可执行的淡水出钓决策。

**支持台钓、传统钓、筏钓** | **9 类水域** | **长江流域保护种否决 + 禁渔区核查** | **农历与月相自动推算**

---

## 能做什么

问一句「明天千岛湖适不适合台钓鲫鱼」，得到的是带分数、带依据、带安全与法规提示的完整方案，而不是泛泛的经验之谈。

- **适宜度评分** —— 白天 / 夜晚分别打分（0-100），给出黄金窗口时段
- **六因子加权模型** —— 温度 25 / 气压 20 / 降水湿度 15 / 风力 15 / 窗口期 15 / 季节 10，合计 100
- **目标鱼种修正** —— 30+ 种淡水鱼的适温区间、活跃时段、摄食偏好
- **水域修正** —— 江河、湖泊、城市河道、黑坑、水库、闸口、山涧、溪流、鱼塘
- **月相影响** —— 自动推算农历与月相，给出夜钓 / 昼钓修正
- **保护种否决** —— 长江流域常见保护种清单，命中即终止并给出法律依据
- **禁渔区预筛** —— 长江十年禁渔、黄河/珠江禁渔期、水源保护区等关键词预警
- **安全否决** —— 雷暴、≥6 级风、高压线、洪水、低温无装备等强制拦截

## 安装

### 方式一：本地安装（当前可用）

将 `dist/freshwater-fishing.zip` 解压后，把 `freshwater-fishing` 目录放入用户级技能目录，重启 WorkBuddy 后生效：

```bash
# Windows
xcopy /E /I freshwater-fishing "%USERPROFILE%\.workbuddy\skills\freshwater-fishing"

# macOS / Linux
cp -r freshwater-fishing ~/.workbuddy/skills/
```

如需团队共用，放入项目级目录 `.workbuddy/skills/` 并提交到仓库。

### 方式二：技能市场安装

在 WorkBuddy 的「技能」页面搜索 **淡水野钓顾问** 安装。

## 工作原理

技能的判断不依赖模型记忆，而是走一条确定性链路：

```
用户提问
   │
   ├─ 1. 脚本采集环境数据
   │     scripts/fishing_conditions.py --location <地点> --date <日期>
   │     → 逐 3 小时气温/气压/湿度/风力(蒲福风级)/云量/降水/雷暴概率
   │     → 农历、月相、照度、日出日落、月出月落
   │     → 节气法季节、禁渔区关键词预筛、安全预标记
   │
   ├─ 2. 否决检查（先于评分）
   │     保护物种 → 禁渔区/期 → 物理安全 → 非法手段
   │
   ├─ 3. 六因子加权评分（白天 / 夜晚）
   │
   └─ 4. 出方案 + 安全法规提示 + 置信度标注
```

**为什么用脚本而不是让模型算**：农历、月相、气压趋势、风力等级这些量，靠模型心算会静默出错且无法察觉。脚本产出的每个值都带来源，拿不到数据时显式降级并说明，不编造。

## 技能结构

```
freshwater-fishing/
├── SKILL.md                          # 工作流主体：约束、四步流程、输出格式
├── references/
│   ├── protected-species.md          # 保护种清单、禁渔制度、不确定处理流程
│   ├── species-activity.md           # 评分模型、鱼种参数、月相规则、水域修正
│   └── tackle-and-rigs.md            # 三种作钓方式线组、味型、钓位速查
└── scripts/
    └── fishing_conditions.py         # 环境数据采集器（零依赖）
```

采用渐进式披露：`SKILL.md` 只保留每次调用都需要的工作流，评价模型、鱼种参数、装备配置等按需加载，避免占用上下文。

## 数据来源

| 数据 | 来源 | 说明 |
|---|---|---|
| 天气、天文 | `wttr.in`（World Weather Online） | 免 API Key，提供未来 3 天逐 3 小时预报 |
| 农历 | 内置 1900-2100 标准农历表 | 本地计算，已用多个已知春节/中秋日期校验 |
| 月相 | 农历推算 + `wttr.in` astronomy 交叉校验 | 两者照度差异 >25% 时给出提示 |
| 季节 | 节气近似（立春/立夏/立秋/立冬） | 不用农历月份判定，见 `references/species-activity.md` §1 |
| 保护名录 | 《国家重点保护野生动物名录》2021 版 | 见 `references/protected-species.md` |

## 重要声明

**这不是法律意见。** 禁渔区、禁渔期、鱼获尺寸与数量限制以**当地渔政部门当年公告**为准，每年可能调整。技能的禁渔预筛只做关键词匹配，不能替代法律判定。出钓前请主动核实。

**关于保护鱼种**：清单一经发现存疑即标注「需核实」而非强行断言 —— 错误断言既可能让用户无谓放流，也可能反过来误导用户违法。遇到不确定的物种，请执行技能内的「不确定处理流程」：不明即放流，并向渔政核实。

**关于安全**：高压线、雷暴、大风、洪水等否决项优先级最高。碳素鱼竿导电，高压线下钓鱼可致致命电击。
